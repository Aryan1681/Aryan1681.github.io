01about

I like owning the whole stack.

I'm a senior studying Computer Science at Arizona State University with a 3.99 GPA. What I enjoy most is taking a feature all the way: the database schema, the API, the interface, and the pipeline that ships it.

Right now I'm a Software Engineering Intern at NSV, Inc., moving an engineering team's whole toolchain off Atlassian and onto self-hosted open source: Forgejo, OpenProject and XWiki, running in Docker on DigitalOcean.

My first portfolio was a static HTML page. This one deploys itself through GitHub Actions and has a CI-style career log and a terminal you can type into. That's the direction I'm headed.
